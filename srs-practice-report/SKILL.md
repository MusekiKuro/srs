# СРС и отчеты по практике

Помогаешь студенту делать СРС / реферат / отчет по практике от темы до готового `.docx` по стандартному ГОСТу.

Почему такой порядок важен: студент не хочет переделывать весь текст, если структура не та. Поэтому сначала согласуй план, потом пиши. И текст должен быть своими словами, а не копипастой из интернета, иначе будут проблемы с антиплагиатом.

## Шаг 0 — Уточни входные данные

Если чего-то нет в запросе, спроси одним сообщением, не начинай работу без ответов:

1. Тип: СРС / реферат / отчет по практике (какая практика: учебная, производственная, преддипломная)?
2. Тема (дословно).
3. Объем в страницах (только основной текст без приложений? уточни).
4. Есть ли особые требования (структура, предприятие для отчета, что исключить)?

Титульный лист НЕ делай — пользователь ставит его сам. Начинай документ сразу с содержания.

## Шаг 1 — Найди материал

- Используй websearch + webfetch для поиска по теме на русском (минимум 5-7 разных источников: учебники, статьи, гос. сайты).
- Не копируй дословно. Пересказывай своими словами, соединяй несколько источников в один связный текст.
- Сохрани все URL и библиографические данные — они пойдут в список литературы в конце.
- Если тема про практику и нет данных о предприятии — пиши нейтрально-обобщенно (например "предприятие / организация"), оставь квадратные скобки `[Название предприятия]` чтобы студент подставил свое.

## Шаг 2 — Предложи план и ЖДИ согласования

Это обязательная остановка. Не пиши полный текст пока пользователь не одобрил план.

Покажи план в таком виде:

```
Предлагаемая структура на N страниц (~X слов):
- Введение (~1 стр): актуальность, цель, задачи
- 1. [Название главы] (~...)
- 2. [Название главы] (~...)
- 3. [практическая часть, если отчет]
- Заключение (~1 стр): выводы по задачам
- Список использованной литературы (7-12 источников)

Подходит? Напиши "ок" или что поменять.
```

Ориентир объема: 1 страница = ~300-350 слов (~1800 знаков с пробелами) при формате ГОСТ.

Логика структуры (одинакова для СРС и отчета):
- Введение: актуальность 2-3 предложения, цель (1), задачи (3-4), объект/предмет, кратко про методы/источники.
- Главы 2-4: от теории к практике. Последняя глава — анализ / примеры / рекомендации.
- Заключение: выводы строго по задачам из введения, без новой информации.
- Список литературы: книги, статьи, нормативка, интернет-источники.

Жди ответа. Если пользователь правит — обнови план и снова жди ОК.

## Шаг 3 — Напиши текст

Только после "ок":

- Пиши научным студенческим стилем: нейтрально, без "я думаю", без сленга, без воды.
- Каждая глава: короткий вводный абзац + 3-6 абзацев сути + мини-вывод в конце.
- Добавляй примеры, цифры, классификации там где уместно.
- Объем держи по плану. Если не хватает — расширь главы, а не растягивай введение/заключение.
- Список литературы оформи по ГОСТ Р 7.0.5-2008 (кратко): номер, автор, название, город: издательство, год, кол-во стр. / URL + дата обращения для интернет-источников.

## Шаг 4 — Создай Word-файл по ГОСТу

Используй `scripts/create_docx.py` из этого скилла. Если скрипта нет — ставь `python-docx` и повторяй его логику вручную.

Параметры нормоконтроля (стандартный ГОСТ, читай `references/gost.md` если нужны детали):

- Шрифт всего текста: Times New Roman 14, межстрочный 1.5, выравнивание по ширине, отступ первой строки 1.25 см, интервалы до/после 0 пт.
- Поля: слева 30 мм, справа 10 мм, сверху/снизу 20 мм. Бумага А4.
- Заголовки: Глава — 14 пт полужирный, по центру, с новой страницы. Подзаголовки — 14 пт полужирный, слева.
- Нумерация страниц: снизу по центру, Times 12. Содержание — страница 2.
- Содержание: вставь автооглавление через поле TOC (чтобы в Word обновлялось по правому клику), а не просто текст. Никаких подсказок типа "обновите поле" внутрь документа НЕ пиши — это предупреждение только для чата. Причина: python-docx умеет вставить только код поля, а номера страниц считает сам Word при открытии, поэтому TOC сначала выглядит пустым — это нормально.
- Не вставляй титульник. Первый лист файла = Содержание, второй = Введение.
- Имя файла: `СРС_Тема_сокращенно.docx` или `Отчет_практика_Тема.docx`.

Проверь перед сдачей:
1. Файл открывается, страниц примерно столько сколько просили (±1).
2. Шрифты/поля/интервалы везде одинаковые.
3. Содержание обновляемое, заголовки — стилями Heading 1/2.
4. Список литературы есть, 7+ источников.

## Шаг 5 — Сдай результат

Отдай: путь к `.docx` + кратко что внутри (кол-во страниц, глав, источников) + напомни: "Правой кнопкой по содержанию → Обновить поле, чтобы номера страниц встали точно" и "Титульник добавь сам в начало".
