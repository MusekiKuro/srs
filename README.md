# SRS Platform

Платформа для студентов: СРС, рефераты и отчеты по практике — от темы до готового `.docx` по ГОСТу.

Репозиторий содержит два артефакта:

```
srs/
├── src/, index.html, package.json   ← веб-платформа (React + Vite, в работе)
├── srs-practice-report/             ← скилл для OpenCode (готов)
├── docs/superpowers/specs/          ← дизайн-спека
└── docs/superpowers/plans/          ← план реализации
```

## Скилл для OpenCode (`srs-practice-report/`)

Делает СРС и отчеты по практике: спрашивает тему/тип/объем, ищет материал в интернете,
согласовывает с тобой план разделов, пишет текст и собирает `.docx` по стандартному ГОСТу
(Times New Roman 14, интервал 1.5, поля 30/10/20/20, автооглавление, список литературы).
Титульный лист не делает — ставишь сам.

### Установка скилла

```bash
cp -r srs-practice-report ~/.config/opencode/skills/
```

### Зависимость скилла

```bash
pip install python-docx --break-system-packages
```

## Веб-платформа (в работе)

Статическое SPA без бэкенда. Ключ ИИ хранит каждый пользователь у себя в браузере,
запросы идут напрямую к выбранному провайдеру. Пайплайн: тема → план → текст по главам
→ правки в браузере → `.docx` по ГОСТу.

```bash
npm install
npm run dev      # локальный запуск
npm test         # тесты (vitest)
npm run build    # сборка
npx vercel --prod  # деплой
```

## Заметки

- Файл собирается без титульника, первая страница — содержание.
- Содержание вставлено полем TOC: в Word нужно «правый клик → Обновить поле».
- Никаких служебных подсказок внутри `.docx` нет — они только в чате/интерфейсе.
